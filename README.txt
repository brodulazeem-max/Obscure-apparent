OPay:
The checkout displays the OPay account number 8137024297, lets customers copy it,
tries to open an installed OPay app via an app URI, and provides a WhatsApp order
confirmation flow. A static website cannot securely verify a bank transfer or
collect an OPay PIN/OTP. Automatic payment verification would require a server-side
payment integration/API credentials and webhook handling.
